## Как устроен английский патч

Английский перевод — это не просто замена строк, а сборочный конвейер `build.py`, который
извлекает файлы из BIN, патчит их и пишет новый BIN (с пересчётом EDC/ECC):

1. **Шрифты.** В exe два растровых шрифта: 12×12 (диалоги, меню) и 10×10 (таблички имён, статусы).
   Латиница взята из полноширинных SJIS-ячеек, выровнена влево; добавлен VWF — таблицы
   пропорциональных ширин (по первому байту SJIS 0x81/0x82) и перехватчики трёх процедур печати.
2. **Сжатие текста.** Диалоги хранятся 16-ричным кодом Хаффмана по полубайтам. Дерево
   перестраивается под английский корпус, плюс «словарь» частых подстрок (до ~2 КБ),
   развёртываемый отдельным обработчиком. Банки переговоров/боя (4–5) — своё дерево A/B
   и свой локальный словарь.
3. **Банки.** Банки 0–5 лежат в `PACKA.BIN` и грузятся в один буфер RAM по 16 секторов
   (32 КБ); банки 6–7 — внутри exe. Банк 4 расширен на сектор, файлы после него сдвинуты
   (таблица файлов в exe переписывается, размер `PACKA.BIN` в ISO обновляется).
4. **Таблицы имён** (демоны, расы, заклинания, предметы…) — в exe, тем же деревом Хаффмана,
   в своих фиксированных областях.
5. **Системные строки** exe — в исходных слотах; английский пишется по 1 байту на символ
   с маркером `0x1F`, при печати байт разворачивается через таблицу в SJIS-глиф.
6. **Оверлеи** (`3DMAP`, `CASINO3`, `OMAKE`, `RAG`, `RDLOGO`), названия локаций (вынесены
   в свободную область exe), меню, экран ввода имени, текстура статуса, ролики (японский
   текст стирается с кадров и рисуется английский игровым шрифтом, видео перекодируется).
7. Десятки исправлений кода (ширины окон, буферы имён, переполнения), размещённые в
   «пещерах» — неиспользуемых участках exe, в т. ч. в ячейках кириллицы шрифта 12×12.

Релизный `SMT2_EN_v0.2.0.xdelta` из папки — более старая версия того же конвейера;
этот форк основан на исходниках master.

## Что добавлено для русского

| что | как |
|---|---|
| Кириллица | 66 букв (А–Я, Ё, а–я, ё) помещены в ячейки **хираганы** (SJIS 0x829F…0x82E0), которая в переводе не нужна. Глифы 12×12 — из стандартного JIS-блока кириллицы исходного exe; 10×10 — нарисованы в стиле английских (`tools/cyrillic.py`). VWF-ширины работают автоматически. |
| Однобайтовые строки | таблица расширена до 256 значений (0x80+ — кириллица) и перенесена в ячейки **катаканы**; поправлены три ассемблерных потребителя и конвертер кэша имён демонов. |
| Больше места | банки 0 и 3 расширены до потолка 16 секторов (+2 и +6 КБ); словарь сжатия вырос (освободившиеся ячейки каны), локальный словарь переговоров переведён на 32-битные указатели и тоже вырос; таблицы рас, NPC, напитков и локаций перенесены в свободную память (было впритык уже на английском); названиям локаций добавлено +0,5 КБ. |
| Встроенные строки | все английские литералы из кода (подсказка бара, «ITEM MAX», «Dismiss/Discard», заголовок сохранений, строки оверлеев, титры роликов, суффикс «'s party»…) собраны в реестр `tools/literals.py` и переводятся как обычные записи. |
| Учёт места | каждая фиксированная область сообщает заполнение (`tools/capacity.py`); пробная сборка без записи образа печатает всё сразу. |

Проверено в эмуляторе (PCSX-ReARMed, headless): дисклеймер и системные строки (однобайтовые,
кириллица), диалоги со вставками имён, имя героя на панели (шрифт 10×10), меню, ширина окна
диалога (~266 px), видеоролик с русскими титрами. Обработчик нового словаря переговоров
проверен выполнением его машинного кода из собранного exe (интерпретатор MIPS).

## Инструменты

| команда | что делает |
|---|---|
| `python ru/extract.py --input BIN --out text` | выгружает весь текст в `text/*.json`: японский оригинал, английский, пустое поле `ru`, ограничения. Повторный запуск сохраняет уже заполненный `ru`. |
| `python ru/merge.py --text text batch.json …` | вливает партии перевода `{id: "текст"}` |
| `python ru/check.py --input BIN --text text --report report.md` | проверка: теги, символы, пиксельные ширины, лимиты слотов + пробная сборка (реальное сжатие всех банков и таблиц) + прогноз заполнения при 100% переводе. Код выхода 1 при ошибках. |
| `python build_ru.py --input BIN --text text [--xdelta]` | сборка `build/SMT2_RU.bin` (+ `SMT2_RU.xdelta`). Принимает все опции `build.py` (`--skip-movies`, `--no-enhancements`, `--output-dir`). |
| `python build_ru.py … --stub-untranslated --skip-movies` | тестовая сборка частичного перевода: непереведённые диалоги заменяются на «~». |
| `python ru/iso.py --input BIN --list / --extract DIR` | список и распаковка файлов образа |
| `python tools/dump_full_script.py --input BIN` | исходный японский дамп банков (из английского проекта) |

Правила для переводчика — в `TRANSLATION_GUIDE.md`.

## Ограничения и что ещё не сделано

- **Объём банков — главный риск.** Банк 4 (переговоры) при английском тексте заполнен на 97%,
  банк 2 — на 94%. Калибровочный перевод ~190 сообщений показал, что естественный русский текст
  сжимается примерно так же, как этот английский (короче по символам на ~7%, но каждая буква
  дороже). То есть влезает, но без запаса: переводить надо сжато и проверять `check.py` после
  каждой партии. Во время перевода смешанный англо-русский корпус сжимается хуже обоих —
  поэтому для тестов есть `--stub-untranslated`.
- **Графика не переведена:** надписи на текстурах — «NEW GAME / LOAD GAME / CONTINUE»,
  «NORMAL / EXPERT» на титульном экране, «EMPTY» на панели отряда, подписи экрана статуса
  (ATK/HIT/DEF…), экран ввода имени (латинская сетка). Это отдельная работа с текстурами.
- Строчная кириллица 12×12 — стандартный JIS-рисунок «капителью» (в, к, т как маленькие
  заглавные). Читается нормально; при желании глифы можно перерисовать в `tools/cyrillic.py`.
- В игре не прогонялись переговоры/бой и экраны, где видны перенесённые таблицы рас/NPC/напитков/
  локаций (по анализу ссылки на эти таблицы есть только в двух-трёх местах exe — они перенаправлены).
  Перед релизом стоит пройти первые бои и переговоры.
- `devtools/emu/` — скрипты headless-эмулятора для Linux (сборка ядра pcsx_rearmed из GitHub,
  фронтенд на ctypes, скриншоты, сохранения состояний).

## Структура

```
build.py, build_ru.py        сборка (английский конвейер + русский слой)
tools/                       модули английского проекта (+ cyrillic.py, literals.py, capacity.py)
ru/                          extract / merge / check / apply / iso / common
text/                        выгруженный текст для перевода (поле ru пустое)
examples/                    черновые русские строки, которыми проверялся конвейер
devtools/emu/                тестовый эмулятор
TRANSLATION_GUIDE.md         правила для переводчика
```

> `text/` содержит японский и английский текст, извлечённый из твоего образа и английского
> проекта, — это производные игровые данные: не выкладывай папку публично (в репозиторий
> английского проекта CI не пропускает игровые данные).
